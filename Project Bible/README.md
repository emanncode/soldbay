# Soldbay Project Bible

Welcome to the **Soldbay Project Bible**. This directory serves as the single source of truth for the Soldbay product ecosystem, which includes the web portal and the mobile application.

Every team member—and every AI assistant—must read and adhere to the specifications and standards detailed in these documents before modifying the codebase.
