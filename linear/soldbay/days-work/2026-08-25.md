| :--- | :--- | :--- |
| **Screen Edge Gutter** | `16px` | `2 × 8pt` |
| **Micro Element Gap** | `4px` / `8px` | `0.5 × 8pt` / `1 × 8pt` |

## 🔍 4. What We Figured Out & Key Learnings
1. **React Native ScrollView Paging vs. Container Padding**: React Native's `pagingEnabled={true}` assumes slide pages match the viewport width. Combining `pagingEnabled` with `paddingHorizontal` inside the `ScrollView` causes page misalignment and visible card bleeding. The correct architecture is to constrain the `ScrollView` inside a parent `View` with `overflow: "hidden"` and `paddingHorizontal: gutter`, giving each child slide `width: SCREEN_WIDTH - 2 * gutter`.
2. **Modular Primitive Composition**: Creating dedicated primitives (`IconButton`, `SearchBar`, `SoldBayInputField`) reduces screen boilerplate by ~40% and ensures that improvements to focus states, dark surfaces, and accessibility labels instantly propagate across all app screens.
3. **High-Trust Campus Visuals**: College marketplaces in Nigeria require a clean, mature aesthetic to foster trust in peer transactions. Transitioning from informal emojis to Figma vector stroke icons immediately elevates user confidence.
4. **Resilient Ref-Based Auto-Scrollers**: Using mutable refs (`activeBannerIndexRef`, `activeStoreIndexRef`) inside `setInterval` closures ensures auto-scrollers always hold the latest state without triggering unnecessary component re-renders or stale closure bugs.
