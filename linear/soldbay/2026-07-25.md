## 6. University Picker — Chevron-Down Alignment Fix

### Problem

The university picker's chevron-down icon used fragile absolute positioning (`top: 20, right: 12`) which didn't align consistently with the input field. The password field's eye icon used `rightElement` prop inside `GlassFormField` for perfect alignment.

### Fix

Replaced the absolute-positioned `View` wrapper with the `rightElement` prop on `GlassFormField`, matching the eye icon's approach. The chevron-down now sits inside the input row, vertically centered, at the same position as the eye toggle.
