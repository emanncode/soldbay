## 5. SecureStore Fix (`soldbay-app`)

### Goal
Fix `ExpoSecureStore.default.getValueWithKeyAsync is not a function` crash on web/Expo Go.

### Root cause
`hasSecureStoreApi()` checked if `SecureStore.setItemAsync`/`getItemAsync`/`deleteItemAsync` are functions — they always are (wrapper functions in `SecureStore.js`). They internally call native module methods that are `undefined` on web, causing runtime errors.

### Fix
Replaced `hasSecureStoreApi()` with `SecureStore.isAvailableAsync()` which checks the underlying native module (`ExpoSecureStore`) directly. On web, `ExpoSecureStore.web.js` exports `{}`, so `isAvailableAsync()` correctly returns `false`. Result is cached after first call. Added `Platform.OS === "web"` shortcut to bypass native import.

### Files modified

| File | Change |
|---|---|
| `soldbay-app/src/lib/auth-storage.ts` | Replaced broken function-existence check with `isAvailableAsync()`, simplified code, removed duplicate web branches |

### Status
**Complete.**
