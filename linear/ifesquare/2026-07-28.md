## 3. Database Cleanup — Clear Registered Users

### Goal

Clear all registered users from the Prisma Postgres database so the same account can be used to sign up again.

### Approach

Ran SQL via `npx prisma db execute --stdin` to delete all user-related data in dependency order:

```sql
DELETE FROM "Session";
DELETE FROM "Account";
DELETE FROM "SellerProfile";
DELETE FROM "Listing";
DELETE FROM "User";
DELETE FROM "WaitlistSignup";
```

### Issues

- Initial attempt failed: `P1001: Can't reach database server at db.prisma.io:5432` — Prisma Postgres instance was paused.
- `npx prisma db push` successfully woke the instance (returned "database already in sync").
- Second `db execute` succeeded: "Script executed successfully."

### Status

**Complete.** All users, sessions, accounts, seller profiles, listings, and waitlist signups cleared.
